# SpaceX Landing Page Clone

A SpaceX-inspired responsive landing page built using **HTML and CSS**. The project recreates a modern space-themed interface with a fixed navigation bar, full-screen video/image sections, overlay text, and call-to-action buttons.

## 🚀 Project Overview

This project is a front-end recreation of a SpaceX-style website homepage. It contains multiple full-width sections covering space technology, launch services, human spaceflight, Starlink, and orbital AI computing.

The HTML structure contains six main sections, while CSS is used for positioning, typography, colors, sticky sections, and button styling.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Remix Icon
- HTML5 `<video>` element
- External SpaceX image assets

## ✨ Features

- Fixed black navigation bar
- SpaceX-style navigation menu
- Full-width background videos
- Full-width image sections
- Large overlay headings
- Descriptive content sections
- Call-to-action buttons
- Sticky scrolling sections
- Google Fonts integration

- Dark space-themed design

## 🧩 Main Sections

### 1. Making Life Multiplanetary
Introduces the project's main space exploration theme with a background video and an **EXPLORE** button.

### 2. Revolutionizing Space Technology
Presents Starship and Super Heavy with a large background image and **LEARN MORE** button.

### 3. World's Leading Launch Service Provider
Uses a video background to present SpaceX's reusable launch technology and includes a **RESERVE YOUR RIDE** button.

### 4. Advancing Human Spaceflight
Highlights human spaceflight capabilities with an image background and **JOIN A MISSION** button.

### 5. Delivering High-Speed Internet From Space
Introduces Starlink and its satellite internet service with a video background and **ORDER NOW** button.

### 6. Developing Orbital AI Compute
Uses a space image and presents the concept of orbital AI computing.

## ▶️ How to Run

1. Download or clone this project.
2. Keep `spacex.html` and `spacex.css` in the same folder.
3. Place the required video files in the project folder.
4. Update the video `<source>` paths in `spacex.html` to relative paths, for example:

```html
<source src="spacex1.mp4" type="video/mp4">
```

5. Open `spacex.html` in a modern web browser.
